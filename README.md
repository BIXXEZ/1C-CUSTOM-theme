## ⚡ Принцип работы и архитектура

Большинство существующих решений для 1С сводятся к редактированию реестра (перекрашивающего только фон текста в редакторе) или внедрению тяжелых надстроек. 

**1C-CUSTOM-theme (DarkMod)** работает на уровне графического пайплайна:

* **Инъекция в память процесса:** Лаунчер определяет запущенный процесс `1cv8` и внедряет компактный модуль `DarkModDLL.dll`.
* **Перехват рендера Cairo:** Библиотека хукает вызовы отрисовщика Cairo (`cairo_set_source_rgb/rgba`, `cairo_pattern_*`, `cairo_mesh_pattern_*`) непосредственно перед выводом интерфейса на экран.
* **Работает в любой базе:** Не имеет значения, файловая это база, серверная, отраслевое решение или чистая конфигурация. Программа перехватывает отрисовку всего процесса глобально.
* **Абсолютная чистота системы:** Никакие системные файлы 1С, конфигурации (`.cf`/`.cfe`) или ветки реестра не патчатся на диске. 
* **Горячее переключение (Runtime Toggle):** Включение и отключение темы происходит налету через экспортные вызовы DLL (`DarkModEnable`, `DarkModDisable`) без перезапуска 1С.

## 🛠 Возможности

* **Единый автономный `.exe`**: Все ресурсы и `DarkModDLL.dll` вшиты в тело лаунчера (`RCDATA`) и распаковываются автоматически.
* **12 семантических семейств цветов**: Раздельная настройка фонов, границ, акцентов, текста и панелей с сопоставлением оттенков.
* **Легковесный UI**: Кастомный темный интерфейс в стиле Catppuccin, написанный на чистом Win32/GDI без сторонних тяжелых библиотек.
* **Изолированные конфиги**: Все рабочие файлы настроек сохраняются в `%LOCALAPPDATA%\DarkMod`.

## 🚧 В разработке (Roadmap)

В кодовой базе уже заложены структуры под следующие функции, доработка ожидается в следующих релизах:

- [ ] **Селектор шрифтов:** переопределение системных шрифтов интерфейса платформы через `darkmod_fonts.ini`.
- [ ] **Анализатор экрана:** сканирование клиентской области окна 1С в реальном времени с построением квантованной гистограммы цветов для точечной отладки перехватываемых оттенков.
- [ ] **Выбор лучших тем через собственный алгоритм:** сканирование окна 1С для создания более 5000 вариацией тем и выборка под критерии пользователя лучших вариантов.

## 🚀 Быстрый старт

1. Скачайте **`DarkMod-Launcher.exe`** из раздела **[Releases](https://github.com/BIXXEZ/1C-CUSTOM-theme/releases/latest)**.
2. Запустите 1С:Предприятие (любую базу или Конфигуратор).
3. Запустите лаунчер.
4. Выберите нужную палитру и переведите переключатель **MOD** в положение **Enable**.
